## 范围与决策边界

- PRD 默认值是提案的显式试点选择，不代表本人已接受实测性能。上线前须以证据冻结模型／tokenizer／证书／SMTP 和资源候选值。
- 请求／知识 MVP 只含 P0。进度卡片、逐事项共享、任务系统集成及自动协商须另做产品变更；此前讨论未修改引用的 PRD。
- 实施新增子系统／安全边界前遵循[仓库 RFC 流程](../../../docs/book/src/contributing/rfcs.md)。这些产物未创建任何批准、holding crate 例外、公开 issue 或 PR。

## 额外明确的设计覆盖

- 未满上限的人员审批独立于问题排队：先保留全部五个产品位置，再考虑第二等待位。答疑规格及任务 4.3／6.5 测此实现选择；不把新造的“队列阻塞审批”体验归给 A19。
- 删除时删改历史来源派生陈述，有意强化 PRD 字面标记规则，避免答案副本残留已删内容。9.4／12.2 测试删改、混合来源陈述和解释占位。
- 除 A06 外发检查，答疑规格及任务 6.2／10.5 覆盖 PRD 8.2 云目标／数据类别披露。
- 实例级原生凭证失效是激活副作用，含私用助手／CLI；由访问迁移场景及 3.1／12.1／12.5 覆盖，不限 personal Web 会话。

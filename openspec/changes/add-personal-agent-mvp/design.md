## Context

输入为 `prd/` 下 PRD v0.6 及其验收／交付附录。本变更实现 F01–F09、F13–F14 的 P0 要求，A01–A23 为发布证据索引。提案定义七项新能力，目前没有 OpenSpec 基线规格。附录 B 默认值在测量前只是候选，不代表现有性能。

仓库证据：

| 现有归属 | 证据与影响 |
|---|---|
| Agent 执行 | `crates/zeroclaw-runtime/src/agent/loop_.rs::agent_turn` 接收显式模型、历史、作用域工具、来源和可选轮次记忆。适配此入口，不走私人助手通用 `run` 路径。 |
| 运行时组装 | `crates/zeroclaw-runtime/src/composition.rs` 定义 source，但头部仍说明处于过渡骨架阶段，不能假定所有注入已经可用。 |
| holding crate 限制 | `crates/zeroclaw-runtime/AGENTS.md` 禁止在此新增子系统。业务存储、队列、通知定时器和 UI 状态归 runtime 外部。 |
| 认证 | `zeroclaw-gateway/src/principal_gate.rs` 将原生配对 Bearer 解析为共享 operator；`zeroclaw-config/src/pairing.rs` 持有配对哈希及独立进程 admin token。访问者不能复用原生配对；现有哈希集合未证明支持所有者绝对到期。 |
| 持久化 | 运行时文档区分配置、记忆、会话和日志；`zeroclaw-infra` 有会话队列，但不能据此保证跨人公平。 |
| TLS 与邮件 | `zeroclaw-tls` 提供传输中立 TLS。`zeroclaw-channels/src/email_channel.rs` 已用 lettre；可复用 SMTP 原语，无需启动收信或注册任意外发 Agent 工具。 |
| UI | 现有 React/Vite 和 `web/src/lib/i18n.ts` 提供前端约定；访问者资源包不得导入仪表盘 operator 认证。 |

新增子系统和安全边界满足仓库 RFC 触发条件，实施跨越边界前须形成持久化决策。OpenSpec 齐备不是 Core 例外或 RFC 批准。不得在 runtime 放新业务；适配器不能使用现有 API 时，先提取所需归属或取得显式限定例外，再修改 runtime，不能静默扩大既有例外。

## Goals / Non-Goals

**目标：** 完整交付知识与请求 P0 MVP：默认本地推理、五人访问、当前策略执行、可恢复业务记录、经过测试的保留、有界外发及完整双方流程。

**非目标：** P1 发现、未读角标、跨机器 Agent 协议、企业登录、逐文档访问者 ACL、任意工具、任务系统集成、逐答案语义正确认证，以及对话中讨论但未进入 PRD v0.6 的进度／状态模块。本提案不隐含性能 SLA 或实际部署。

## Decisions

### 1. 领域模块与组装

新增 `crates/zeroclaw-personal`，承载领域服务、SQLite 迁移、personal 资源授权、调度及保留。依赖 `zeroclaw-api` 契约，不依赖网关或 runtime 实现。网关／根应用注入执行、时钟、通知及所有者权威适配器；根应用每个启用 generation 构建及关闭服务一次，网关只提供适配与监听组装，不另造 Agent 循环。

复用现有异步／数据库／HTTP／TLS 库，通过窄邮件适配器复用 lettre，不依赖完整收信生命周期。仅在有实际生产调用方及具体需要时增加有限特性的依赖。后台任务使用 `zeroclaw-spawn` 和 generation 取消／排空规则。

替代方案：全部放 runtime 或网关 `AppState`。因 runtime 明禁新子系统、网关应只负责传输而不采用。纯 WASM 方案延期：插件 API 尚未证明可满足访问者认证、独立监听及持久调度契约。

### 2. 权威来源与存储

使用私有 `<data_dir>/personal/personal.db`，启用 SQLite WAL、外键、仅所有者文件权限、版本迁移及事务写入。数据库写操作跨异步安全的阻塞边界，不跨 await 持同步锁。已发布正文作为普通数据保存在显式 OS 隔离部署中，不宣称应用层静态加密；配置秘密复用现有类型化加密。

| 新建事实 | 唯一权威归属 | 派生界面 |
|---|---|---|
| 部署意图、模型引用、TLS 路径、一份 SMTP 绑定、开关、时区、预算候选值 | 类型化 `Config.personal_agent`，引用已有模型及 Agent 配置 | 从当前配置解析的表单及已验证适配输入 |
| 原生所有者凭证签发／到期／撤销 | 扩展为权威 token 记录的既有配对机构 | 浏览器会话引用原生 token 身份，不复制权限 |
| 访问者人员授权、审批链、会话到期及撤销 | personal DB 访问记录 | 逐操作解析的人员上下文及有效人数 |
| 知识正文／版本、复核及未处理反馈 | personal DB 来源／版本记录 | 索引、到期／宽限状态、复查表及来源响应 |
| 访问者会话、消息及答案归因 | personal DB 会话记录 | 按人限定的模型历史、待反馈及保留期限 |
| 协作请求、状态、期限、转换及回复 | personal DB 请求及转换历史 | 收件箱、超窗提示、争议次数、通知选取、指标 |
| 通知尝试、租约、SMTP 结果及汇总投递身份 | personal DB 投递账本 | 渠道健康、重试资格及去重 |
| 所有者手工日终估时和显式答案复核 | personal DB 试点记录 | 不复制问题正文的汇总指标 |

不得在长生命周期句柄保存 `is_stale`、`is_overdue`、人数、请求状态镜像或当前权限快照。资格与期限是权威记录加注入时钟的视图；投递账本只描述传输。有效接待由本人显式意图、请求通知开关、已验证绑定健康、未解决暂停确认及等待时长计算；自动暂停是带归因事件，不是第二套请求队列。

新配置写入全部走既有 config-commit 写入及发布路径；凭证有类型化秘密标记，不临时读取环境变量。配对变更使用同一持久化授权权威；索引从数据库版本重建，不能授权读取。

### 3. 控制面与访问者传输隔离

保留已有所有者 Gateway 的回环绑定并使用 TLS。另组装 TLS 访问者监听器，自建白名单路由并服务独立访问者资源入口，不挂已有仪表盘、`/pair`、`/admin`、`/api/config`、通用聊天／WebSocket、文件、日志、记忆或插件路由。若启用实例会暴露控制面，或 TLS 缺失／不可信则拒绝启动。复用 `zeroclaw-tls`，提供明确证书配置流程，使用私有 CA 或组织可信证书，绝不要求关闭验证。

所有者路由位于 `/api/personal/admin`，访问者位于 `/api/personal`。各 Origin 使用不同名称的 host-only、HttpOnly、Secure、SameSite Cookie 和服务端哈希化不透明会话；变更有 CSRF 防护、显式 Origin 白名单，不使用携凭证通配 CORS。访问者认证拒绝 operator/admin token，operator 认证拒绝访问者凭证。回环 Host、Origin 及可信代理校验防重绑定／转发。远程管理须经已认证主机隧道，不靠放开远程管理配置。

公开页只展示代理身份及申请入口。详细本人卡片及可选工作联系说明授权后可见。邮件无凭证导航到本人确认的回环／隧道 Origin；其他设备打开不暴露管理，也不静默替换局域网 URL。

### 4. 所有者权威与访问者生命周期

扩展现有配对 token 记录，不另建并行到期表或仅装饰浏览器 Cookie。权威纯哈希集合改为含哈希、签发时间及可选到期时间的记录，序列化兼容禁用部署。启用 personal 时使缺可信签发／到期信息的原生所有者 token 失效并要求本地重配。该迁移影响整个实例：已配对私用助手、CLI 及其他原生 operator 会话也失去访问，不只 personal UI。提交迁移前必须展示影响范围、获得本人确认并提供本地恢复／重配流程。

验证时从已接受配置解析启用策略，所有者有效期候选为八小时。共享该权威的原始 Bearer、派生浏览器会话、WebSocket／RPC 重查及受控副作用均执行到期。禁用态保持既有无到期行为；启用不能遗留旧端点绕过。迁移前审计调用点并测试每种接收传输。复用撤销及持久化，不缓存复制授权。独立进程 admin token 仅本地用于取得配对码。

正常到期／登出后，由可信本地终端取得新短期单次码，重新登录。泄露恢复还须关闭入口、撤销并持久化受影响 token／会话、轮换进程 admin 再配对；只发新码不够。operator 泄露可能影响整个实例，而非仅 personal 记录。

访问者邀请 token 候选十分钟，只创建待审，不授予人员权限。邀请通过 URL fragment 输入、POST 兑换后清理地址，避免 token 进入 HTTP 路径／访问日志。申请者取得窄权限待审 Cookie，仅轮询自己结果。待审实际 72 小时到期，可关联手动续提一次，第二次到期需本人新邀请。不宣称可跨设备重新识别匿名人，以邀请、链身份及限频约束滥用。

本人经既有渠道核实身份，显式关联已有或新建人员，再原子批准浏览器会话。最多五个有效人员授权，不含本人。已有人员新设备不占新人名额；整人撤销释放。重批可发新凭证，但未经本人显式决定不能恢复撤销身份。访问者绝对有效期候选 30 天，每次请求、最终响应及来源访问均查到期／撤销。

### 5. 发布知识与隔离答案

来源使用不可变版本、本人责任人、原始引用、发布及显式确认记录。外部原始来源必须是无内嵌凭证、无含秘密查询／fragment 参数及无脚本协议的 HTTPS URL；仅作归因，不自动抓取。发布前以字段错误拒绝无效引用，不记录所含凭证。复查默认 30 天、可选 7／30／90。编辑产生新版本，查看／索引／答疑不刷新确认。当前有效版本中，已确认优于仅时间到期宽限；只有时间到期享受 `[due, due + 7 days)`。未处理失效反馈、已知错误、撤回及撤权立即排除。七天边界从新答案上下文排除，旧索引命中也无效。历史读仍查权限及旧版标签，撤回／删除正文不可读。

小试点对发布片段使用可重建本地词法索引及 CJK 分词；选择 FTS5 前验证 SQLite 特性。不要求远程嵌入，不复制通用记忆。后续若需语义检索，嵌入路径也受同一本地外发策略约束。缺搜索后端按失败关闭原则处理，不能回退无限制文件搜索。依据不足用确定性说明／转交，不自由生成个人事实。

网关适配器调用已有 `agent_turn`，仅传专用对外身份、校验后的有界来源片段及该访问者获权历史。不传私人轮次记忆、人格文件、技能／MCP、通道上下文、提示附件、委派、模型切换或执行工具。空作用域工具注册表，拒绝工具调用输出。只进行一轮答案生成，无自主工具循环；接入前证明现有入口能按控制实现。若证明失败，先解决适配／提取，不另写自定义模型循环走捷径。

提示组装及模型输出均不可信。新轮次移除不可用来源派生历史，引用失去资格后不能复用旧答案。原生提供方调度继续负责推理及用量。仅本地的已接受策略逐路由、重试和回退解析并阻止外发，含辅助草稿；未知端点须显式分类后接入。禁止本地轮次中途切云，当前策略不再允许的结果不得发布。

启用或更改云目标／数据范围前展示模型提供方／目标及可能外发类别：当前问题、有界历史、发布来源片段、对外系统／身份指令及启用的草稿提取输入；明确排除私人助手上下文。调度前本人须确认披露范围，记录目标／范围同意但不另存提示正文快照；新增目标或类别需重确认。拒绝／取消保持云调用关闭；邮件同意不等于模型外发授权。

生成有界 JSON `claims` 封装，单元为 `{text, references:[{source_id,version,chunk_id}]}`。服务端校验结构、大小、当前来源状态及权限，再从元数据计算宽限标签。非事实提示用固定本地化应用模板，不能让模型选择逃逸类型。整体正文校验成功前不对外暴露；畸形输出只返明确失败／转交，不展示原文或第二次修复生成。安全文本／Markdown 渲染，不支持原始 HTML。来源 UI 解析获权数据库片段，不使用模型 URL。引用有效不证明语义；离线／抽检覆盖支持错误、冲突、编造及恶意资料。

### 6. 调度、限制与取消

队列初始候选为一运行、五等待。从启动起为五个产品人员位置各留首等待位，含未分配位置，未来空位不借出；因此五等待槽时每人最多一个等待任务。第二等待位只能来自五预留之外的额外配置，仍每人最多两等待加一运行。少于五等待槽在服务前即判无效，不作为拖延审批理由。未满五人审批独立于问题占位，不能因既有人多提交而失败。这是以闲槽利用率换取不新增审批障碍的保守取舍；PRD 规定“最多两位”，不是保证两位。按人轮转、同人 FIFO，多浏览器按人合并；同会话串行化为下级边界，防冲突轮次。

入队前校验字符／字节／token 和按人／实例滚动限频。候选为 4000 Unicode 字符、16 KiB UTF-8、每人每分钟六题、实例每分钟二十题。实际模型 tokenizer 执行候选总 8192 预算：系统 2048、问题 2048、检索 2048、历史 1024、输出 1024。上线前冻结支持的 tokenizer／模型映射，不支持则配置失败，不静默估算。UI 解释双限并观察中文拒绝；不能截断当前输入或安全指令，历史裁剪可见且剔除撤权来源。

不透明问题幂等键限人及会话。同内容重试加入既有操作／结果，只计一次；同键异内容冲突，不延长原期限或并发生成。问题键不当作协作请求编号。

候选 60 秒含排队、检索、生成、确定性校验及交付准备。模型正文缓冲，等待只显示处理状态。取消、到期及 generation 拆除释放容量并隔离迟到发布／历史持久化。进行中工作不支持重启续跑，标中断并允许显式重试。失败／过期问题不创建协作请求，原始载荷不进入日志及 observer。

### 7. 协作请求与 API 契约

personal SQLite 是唯一业务来源，与 runtime subagent／任务注册表分离。模型停机也可手填草稿。可选模型提取／摘要为独立、有界、无动作操作，使用相同隔离及外发控制，请求者编辑确认后才提交。本人回复手写，不提供引用块、自动复制原文或模型代拟。

保存类型、标题 1–100 字、单一背景／帮助 1–4000 字、可选影响最多 1000 字、含时区期望时间、最多五个 HTTPS 链接及 PRD 6.4 精确定义的专属字段。必填未知阻止提交，可省略项明确。期望时间校验为未来时刻，校验脚本／凭证／超长 URL 并安全转义，不抓链接、不收附件。身份来自认证而非模型。提交捕获原文、可编辑摘要及当前首次处理窗口；请求和幂等记录原子提交后返成功，同一接入边界检查请求通知前提及暂停。

| 当前状态 | 操作者／动作 | 结果 |
|---|---|---|
| 草稿 | 请求者提交有效草稿 | 待本人处理 |
| 待本人处理 | 本人接受／拒绝／要求补充 | 已接受／已拒绝／待补充 |
| 待补充 | 请求者确认补充 | 待本人处理，捕获新进入期限 |
| 待补充 | 本人接受／拒绝 | 已接受／已拒绝 |
| 已接受 | 本人提交结果 | 待请求者验收 |
| 待验收 | 请求者确认／争议 | 已完成／已接受并附说明 |
| 非终态 | 请求者撤回 | 已撤回 |
| 已完成／已拒绝／已撤回 | 请求者重发 | 新关联草稿，原记录仍终态 |

变更要求记录版本，竞争更新返当前状态及冲突，不最后写入获胜；追加转换／消息，不覆盖原字段。争议不人为限次，次数派生。默认待处理 24 小时后列表／详情显示超窗及复制摘要，状态不变；配置不改写捕获期限。待本人处理 72 小时影响接待暂停，待补充／待验收不影响。

拟定类型化传输入口，均在各监听专属路由下：

| 对象 | 资源 | 操作 |
|---|---|---|
| 待审／公开 | `landing`, `invitations/redeem`, `applications`, `applications/self` | 最小页面，POST 兑换／申请／续提，GET 本人结果 |
| 访问者 | `identity`, `session`, `conversations`, `questions`, `questions/{id}/cancel`, `answers/{id}/feedback`, `sources/{id}/versions/{version}`, `source-reports` | 受权身份／登出、本人会话、有界异步提问／状态、反馈及获权来源／报告 |
| 访问者 | `requests`, `requests/{id}`, `requests/{id}/actions`, `requests/{id}/content` | 提交／列出／读取本人请求，补充／撤回／验收／争议，撤回后自删 |
| 所有者 | `access/applications`, `access/people`, `access/devices`, `knowledge`, `requests`, `notifications`, `intake`, `pilot`, `recovery` | 审批／撤权、发布／复查／撤回／删除、手工决定／结果、已验证设置、暂停／恢复、复核指标／耗时及可信恢复 |

错误统一 `{code,message_key,args}`，不含模型／数据库原始细节。语义为：401 到期／未认证，403 禁止，404 无权资源且不枚举，409 版本／幂等／容量冲突，413 字节超限，422 校验／token 超限，429 限频／队列过载并提示重试，503 不可用／接待关闭，504 问题超时。模型操作返回问题 id 及可轮询状态，进度端点不流出未校验内容。申请轮询仅用待审凭证，不枚举人。类型模式生成前端契约，不另抄模式表。

### 8. 通知与后台生命周期

一份类型化加密 SMTP 绑定，另持久化验证结果及请求／申请／复查三个当前开关。绑定变更撤销验证，验证前不能启类别。本人确认测试邮件，可用短期 challenge，绝不含 operator token。确认后知识复查默认开，其他开关显式选。接待还需请求开关及健康投递；关请求暂停接待，关其他不影响。不另建第二 SMTP 配置。

每日 09:00 使用 Config 内本人确认的 IANA 时区，不随浏览器／主机位置。日期及类别感知投递身份防重复；夏令时缺失顺延首个有效当地时刻，重复只发一次。改区预览下次且不重放旧日期。SMTP 真实边界是至少一次：接受后、持久回执前崩溃可能重复。用稳定 Message-ID 和账本租约，不宣称恰好一次或本人已读。

邮件只含代理名、数量、最老等待时间及附隧道说明的本人导航，不含问题正文、资料标题或第三人联系方式。启用复查汇总在认证工作台列出本人可见来源标识，而非邮件正文，临期／宽限资料在那里逐份可处理。日汇总只含启用类别的待审及滞留项。请求者待补充／待验收第三天提醒在认证访问页，下次访问展示一次，不新建访问者邮箱或第二绑定，不假称已触达离线人。

首次超窗默认待处理 24 小时，每日最多一次合并提醒；待处理 72 小时暂停新接待，直到本人确认并显式恢复。待补充／待验收第三天提醒、连续七天进入每日滞留表；已接受七天无更新也加入。不自动完成／拒绝。首次失败后 5 分钟、30 分钟、2 小时重试，最终失败以健康门控关闭接待。失败不改业务状态。重启重算遗漏并一次合并，不突发轰炸；SMTP 交接前重查开关、当前记录及删除屏障。

### 9. 保留、反馈与试点

会话从最后消息而非阅读起 30 天到期。转交后的请求独立，终态起 30 天到期，不因后续阅读／评论延长。到期清正文、回复、相关来源派生载荷、状态及人员关联，不造新回执。撤回后可删请求者自己内容及系统派生物，独立本人回复留至原期限；明确披露手工复制／转述不自动识别，本人可删误贴回复。提前删除回执只留请求 id、终态、删除时间及最小授权关联，不留展示身份／正文／链接，在删除后 30 天与原终态后 30 天的较早者到期。

数据库、索引、队列、活动生成、导出及投递屏障须一起实现。删除后旧正文不能经答案缓存或历史注入再现；删改历史答案中来源派生陈述，保留不可打开的引用标记。这是超出 PRD 字面“引用不可用”的显式加强，否则已删正文可能以转述答案残存。利用陈述到来源的归因，替换为有说明的内容不可用占位；混合来源任一支持被删也隐藏该陈述。UI 说明历史被移除，而非原答案本来为空。仅撤回限制后续读取／复用，历史正文删改针对删除。此派生规则由任务 9.4／12.2 测试，不冒充新增 PRD A 项。撤回不承诺擦除已接收副本。

SQLite 逻辑删除的运维方案包含 WAL／checkpoint／压缩和备份，不承诺 SSD 页或外部备份取证级擦除。恢复备份时须重放删除策略，不能静默恢复已删行。启动和周期任务均用注入时钟清理。

反馈包括已解决／未解决和 48 小时内每个合资格未反馈问题至多一次合并回访，不邮件、不阻断，删除后不回访。解决／未知率只纳成熟问题，零分母不适用，晚反馈单列。复核区分资料／模型／混合／待定位，报告触发与随机样本分开。到期／宽限／答案比例、及时率、积压、维护和净收益按 PRD 公式，不造综合成功分。记录日终三数及计入维护的隧道／再认证次数耗时，不重复计数。

### 10. 界面与本地化

在现有 Web 工具链建立独立双方入口。访问者包包含落地／申请、有界提问／历史／来源、反馈、请求表单／详情／验收及删除确认；所有者含设置／认证、人员／设备、发布／复查、收件箱／手工结果、邮件验证／时区／开关、暂停／恢复及试点复核。访问者入口不共享 operator 存储。错误／空／超窗／宽限／删除态均为 UI 契约，待复核中性，不是红色故障。

Web 用 `web/src/lib/i18n.ts`，运行时 CLI／工具／引导用文档规定的 Fluent required-string helper，不硬编码或另造 catalogue。日志保留英文稳定码，无个人正文。部署、TLS、SSH 隧道、重配、邮件、删除及回滚编写英文源文档；中文 `prd/` 是评审输入，不复制到 `docs/book` 生成译文。

## Risks / Trade-offs

- [原生 operator 权限覆盖实例] → 保持回环管理，披露影响，隔离 OS 部署并测试全部 token 消费方；仅短 Cookie 有效期不够。
- [本地模型可能不达候选时延] → 公平有界队列、实测模型分词及硬件、取消迟到结果；试点前冻结证据，不保证候选 60 秒。
- [引用可能支持错误内容或误读正确内容] → 确定性准入加离线语料和人工复核，分开归因，不把结构校验当真值验证。
- [维护吞噬节省时间] → 宽限标签、复查汇总、显式暂停及含隧道／再认证的日估时。
- [SMTP 不证明已读或恰好一次] → 账本、稳定 ID、有界重试、明确健康／接待门控和真实超窗展示。
- [手工副本及存储残留绕过自动删除] → 披露范围、不存正文遥测、隔离活动任务、测试逻辑删除，记录备份／压缩限制。
- [仓库边界禁止方便的 runtime 修改] → 用现有 API 及领域 crate；适配证明失败先提取或取得有记录限定例外。

## Migration Plan

1. 记录子系统／安全 RFC 和归属，证明适配入口并冻结试点技术值，不把本产物视为批准。
2. 增量增加类型化配置和 DB 迁移，默认关闭；有限原生 token 记录兼容禁用安装。激活必须明确警示并确认：含私用助手／CLI 的全部实例客户端中时间信息不明的旧原生 token 失效，须本地重配，不能描述成仅 personal 会话重置。
3. 在回环启动本人界面、验证 TLS，访问者仅最小路由且接待关闭；建立本人身份、对外 Agent、共享知识、可信证书和批准人员。
4. 在真实 HTTP／浏览器边界验证 A01–A23、无外发、本地模型基准、重启／故障／删除、SMTP 沙箱，并验本地化及生成契约。
5. 验证一份邮件绑定，确认开关／时区，显式开接待；基线后两周试点，不静默启 P1。
6. 回滚先关接待及监听、禁用模式、排空／取消工作；验证认证配置后才保持普通 ZeroClaw 服务。撤销 personal 会话及到期本人 token，不复活旧凭证。升级前备份受保护配置及 DB，显式迁移修复／恢复，不自动破坏性降级。删除和已送邮件不可逆，备份恢复须先对账保留／删除再服务。

## Open Questions

待定是发布选择而非缺失 P0：具体本地模型／tokenizer、证书分发、附录 B 时延／资源候选及组织批准的 SMTP。默认值指导实现测试，部署激活前须显式验证。冻结一运行／五等待时须同时确认每人只有一等待位；超过五预留容量后“两位上限”才有实际作用。不得为基准静默放松认证、外发、输入或删除要求。SMTP 不可用可交付仅答疑，但不能声称请求接待验收通过。

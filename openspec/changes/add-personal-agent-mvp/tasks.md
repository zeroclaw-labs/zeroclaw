## 1. 架构与发布前置条件

- [ ] 1.1 记录新增子系统／安全边界的 RFC 决策、归属及兼容性条件；不将本 OpenSpec 变更视为批准，不在未获授权时向外提交。
  进度：RFC 文稿已按仓库七段结构起草于 [rfc-draft.md](rfc-draft.md)（Problem／Proposal／Design／Alternatives／Non-goals／Risks／Rollout，AI 起草、待人类发起人担责）。**未提交**：按任务约束与 RFC 流程（`docs/book/src/contributing/rfcs.md`），提交 GitHub Issue 并经 Core 投票批准需要发起人授权。批准前不开始 2.x 及以后的子系统实现。
- [x] 1.2 用现有入口测试夹具证明 `agent_turn` 可执行一次无工具的对外答疑，不注入私人记忆／人格／技能／附件，不提前输出正文；若已有 API 无法满足，先解决提取或取得有记录的限定例外。
  证据：`crates/zeroclaw-runtime/src/agent/loop_.rs` 测试模块新增两个夹具测试，`cargo test -p zeroclaw-runtime --lib agent_turn_outward` 全部通过（2 passed）。
  ① `agent_turn_outward_answer_single_round_without_tools_or_private_context`：空密封注册表 + `memory: None` + `config: None` 下，录制型 provider 断言恰好一次生成调用、请求消息与调用方提供内容逐字节一致（无人格／记忆／技能／附件注入）、`tool_spec_count == 0`、turn 期间 spy Channel 零次发送（无提前发布）、注入前导为 `None`。
  ② `agent_turn_outward_answer_drops_tool_output_without_second_generation`：模型返回原生工具调用且无文本时，解析层丢弃该调用，turn 确定性终止、结果为空、无第二次生成、零发布。
  结论：现有 API 可满足适配器需求，无需提取或限定例外。生产空注册表经 `ScopedToolRegistry::assemble` 空集组装；测试夹具用 `from_raw_for_test(Vec::new())` 等价表示同一密封类型。
- [x] 1.3 审计所有原生配对 token 消费方和现有 Web 凭证存储；标明 HTTP、RPC、活动连接的权威到期、撤销、CSRF 和隔离执行点。
  证据：[native-token-audit.md](native-token-audit.md)。要点：权威机构为 `PairingGuard` 纯哈希集合（无签发／到期元数据，持久化于 `Config.gateway.paired_tokens`）；RPC 路径已有 `Principal.expires_at` 检查基建（原生共享 operator 恒为 `None`，可在准入时打标复用）；网关 HTTP（require_auth 31 处、webhook）与 SSE／WS 四个流surface直连哈希集合、其中 SSE／WS 仅连接时认证无存活重查（撤销延迟边界，personal 业务面不得继承）；Web 凭证为 localStorage 明文 bearer + Authorization 头（无 cookie 无 CSRF，但页面脚本可读——personal 所有者会话须用服务端哈希会话 + HttpOnly cookie 新机制，不复用 `lib/auth.ts`）；进程 admin token 与配对码管理路由（`require_gateway_admin_token`）已有宿主本地文件交付与常量时间比较。
- [x] 1.4 选择本地测试模型及真实 tokenizer、TLS 证书分发和 SMTP 沙箱；记录附录 B 候选值及基准协议，不宣称已可试点。
  证据：[benchmark-freeze-protocol.md](benchmark-freeze-protocol.md)。候选模型 `qwen3:8b`（经现有 `ollama` provider，CJK 强、适配 4 核 16 GiB 候选硬件），备选 `llama3.1:8b` 或 `compatible` provider；tokenizer 两条路线（Ollama `/api/tokenize` 服务端精确计数优先，或 HF `tokenizers` crate 以固定哈希的 `tokenizer.json` 内嵌于 `zeroclaw-personal`，不进 runtime），不支持时配置校验失败、无静默估算回退；上下文窗口须以 `Configured` 来源 ≥ 8192；TLS 走私有 CA＋组织信任分发（开发用 mkcert，绝不关闭校验）；SMTP 沙箱用 Mailpit（支持拒绝／收后丢弃／慢接受三种故障注入），试点用组织 SMTP。基准协议固定环境、语料（CJK 重）、计时分解、五人负载脚本、外发拦截全程开启，缺失值只报告不放宽。状态：未试点就绪，模型选择待试点负责人确认。

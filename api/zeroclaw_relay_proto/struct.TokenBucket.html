Struct TokenBucket 

pub struct TokenBucket { /* private fields */ }
Expand description

A simple monotonic token-bucket rate limiter (std only, no background timer).

Refills continuously at refill_per_sec up to capacity; each admitted event costs one token. Used to cap abusive rates (A6): connection handshakes per source IP at the relay, and per-node OPEN handshakes at the daemon bridge so a flood cannot force unbounded loopback mTLS handshakes. Cheap and lock-guarded by the caller; not payload-aware (it counts events, never bytes).

pub fn new(capacity: u32, refill_per_sec: f64) -> Self

A bucket that starts full with room for capacity burst events, refilling at refill_per_sec. A zero/negative rate makes a fixed capacity-event allowance that never refills.

Source

pub fn last_activity(&self) -> Instant

When this bucket last saw an event. The relay uses it as an LRU key: a flood spread over many sources leaves every bucket partially drained, so pruning full buckets alone cannot hard-bound the tracking map and the least recently active entries have to be evicted instead.

Source

pub fn is_full_at(&self, now: Instant) -> bool

True when the bucket is at full capacity (no recent activity) - the relay uses this to prune idle per-source entries so the tracking map stays bounded.

zeroclaw_runtime::observability

Module broadcast 

Expand description

The process-wide observability event bus.

BroadcastObserver turns ObserverEvents into the JSON frames that /api/events (SSE) and RPC logs/subscribe deliver, and keeps the most recent ones in an EventBuffer for history replay (/api/events/history, RPC events/history). EventBus bundles the live sender with that buffer. The daemon owns one bus and installs its observer as the global broadcast hook exactly once, so agent, tool, and LLM frames reach RPC subscribers whether or not the gateway runs; a standalone gateway builds and installs its own.

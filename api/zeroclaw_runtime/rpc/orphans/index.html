Module orphans 

Expand description

Retirement of orphaned remote sessions.

A remote client’s sessions stay live after it disconnects, so that it can reconnect with its identity and carry on. A client that never comes back, or comes back under a new identity (which cannot reach them), would otherwise hold its places in the daemon’s live-session map until a restart. Once the owning identity has had no live connection for wss.orphaned_session_timeout_secs, each of its sessions that has been idle as long, has no turn running and has no approval pending is closed, as session/close would close it. Retirement never writes a transcript: a chat session goes only when its store already holds all of its history, and one whose store lacks part of it, differs from it or can’t be read stays live. Only the live session goes.

retire_orphaned_sessions
Close every orphaned remote session that is due at now and return the ids closed. Also forgets the departures of identities that no longer own a live session.
spawn_orphan_retirement
Run retire_orphaned_sessions until cancel fires or ctx is dropped. The task holds ctx only while it checks, and a check stops at its next safe point once cancel fires, so a finished daemon generation is not kept alive or changed after it is told to stop.

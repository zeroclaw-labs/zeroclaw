fn authz(self) -> MethodAuthz

Authorization classification (RFC 7141 gate-by-construction). The match is arm-complete over the closed Method enum, so adding a variant without classifying it is a COMPILE ERROR — a new method cannot be dispatched unclassified. The explicit MethodAuthz::Handshake sentinel (rather than an Option) keeps every ungated method greppable and deliberate; initialize and mTLS certificate renewal are the only transport-authenticated ones.

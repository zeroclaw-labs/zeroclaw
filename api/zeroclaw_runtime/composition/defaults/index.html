The config-backed sources the compatibility adapters use, for an application layer that composes the same recipe.

ConfigMemory
Opens the agent’s memory with the agent provider’s credential, which embedding resolution inherits when [memory] names none of its own.

Builds the routed, resilient provider the turn loop and the agent built, and the agent’s config-snapshot provider on a model switch.
NoOutboundChannels
The config-backed channel source. Despite its name it serves one channel: the cli alias, from the CLI channel factory the application registered. Every other alias is None; outbound channels are not routed through it.
NoSuppliedTools
Every tool is still built by the runtime’s own registry, so the config-backed set supplies none of its own.

Supplies tool registries.

Required Methods§

fn tools(&self, request: &ToolRequest<'_>) -> Result<Vec<Box<dyn Tool>>>

The tools this source supplies for request.

Without a native recipe they are the whole registry; with one they are added to the native tools, and a source tool whose name a native tool already has is dropped. If two of these tools share a name, the first is kept. Every dropped tool is logged. Either way the agent’s policy, the caller’s allowlist and the memory/delivery context filters still apply.

The tools are built before any principal routing of the session’s memory, so a source memory tool built on request.memory keeps using that handle; routing applies only to the runtime’s native memory tools.

fn native_recipe<'s>( &'s self, _request: &ToolRequest<'_>, ) -> Result<Option<&'s NativeRegistryRecipe>>

Chooses how the registry for request is built. Called once per build.

Return Ok(None) (the default) to make ToolSource::tools the whole registry, even when it is empty. Return Ok(Some(recipe)) to have the runtime build the native registry with recipe and add this source’s tools to it. An error here, or from the recipe, ends the build.

This must not do I/O or use request.memory beyond comparing identity. Bounded delegation calls only this method, never the recipe or tools(), so a refusal that must also cover bounded delegation belongs here. The returned recipe may borrow from the source, not from request.

Module relay_dashboard 

Expand description

The in-process handoff from the relay bridge to the gateway for a dashboard that a relay serves ([relay.dashboard]).

A browser that opens this daemon’s dashboard through a relay ends its TLS at the relay, which forwards the plaintext HTTP over the daemon’s own outer relay link. The bridge must not hand that stream to the gateway’s TCP listener: a connection from 127.0.0.1 is a loopback peer, and the gateway gives loopback peers standing - the admin routes, the limiter exemptions, SOP cancellation without pairing - that a browser on the internet must never get. The bridge passes the stream over in process instead, as a DashboardConn carrying the browser’s address, which is never loopback by construction, and the one origin the dashboard is served at.

DashboardIngress is the meeting point. The gateway generation that is serving attaches to it and receives connections; the bridge delivers to whichever generation is attached and refuses the route when none is.

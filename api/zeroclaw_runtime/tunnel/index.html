Classify a tailscale status outcome. Only a usable identity (TailscaleSelf::has_identity) is Resolved. A failed or timed-out query, malformed output, and a successful status reported before tailscaled has its network map are all Unavailable, so the existing certificate keeps its names instead of being regenerated without them.

Resolve the tailnet names for the daemon’s self-TLS listeners (WSS, enrollment). Queries tailscaled only when the listeners are reached over the tailnet. Callers that start several listeners must resolve once and share the outcome, so every listener presents the same identity.

pub fn attachment_deliver_uri(id: &str) -> String
Expand description

ACP / model citation URI for an outbound delivered file.

Source of truth for the attachment://deliver/<id> string, where <id> is the opaque content hash from content_hash_name — never a caller-supplied filename. ACP must reuse this helper (or the uri carried on the tool’s zeroclaw_api::agent::ToolArtifact), not a second formatter.

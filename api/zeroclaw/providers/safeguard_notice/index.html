Module safeguard_notice 

Expand description

Task-local side-channel for safeguard (refusal-triggered) model switches.

Mirrors the task-local contract of crate::reliable::ProviderFallbackInfo: the accepted-response owner commits at most one notice per turn via commit_safeguard_fallback, and the runtime turn boundary reads it via take_last_safeguard_fallback. Both must run inside a scope_safeguard_fallback scope for the data to be visible; outside a scope, commit/peek/take are silent no-ops.

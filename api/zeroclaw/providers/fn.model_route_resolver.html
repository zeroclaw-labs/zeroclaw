pub fn model_route_resolver(
    primary_name: &str,
    model_routes: &[ModelRouteConfig],
    default_model: &str,
) -> Arc<ModelRouteResolver> ⓘ
Expand description

The route resolver a routed provider built from these arguments carries, derived from config alone.

For a caller that obtains its provider from somewhere other than create_routed_model_provider_with_options_and_resolver but still needs route-aware turn metadata and limits. It applies the same staged-entry filter, and a successfully built routed provider keeps every materialized route, so the two resolvers agree.

build_session_model_provider with the provider obtained from capabilities, resolved for agent_alias and principal. For session surfaces (RPC) that swap a session’s provider for a connection principal.

The reference and model are validated and resolved exactly as there; the route resolver is derived from the same config routes the routed provider is built from.

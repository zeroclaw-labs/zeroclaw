Expand description

Fixed per-image charge for [IMAGE:...] markers in the history estimate. Approximates the standard-tier Anthropic maximum (1,568 tokens for an image at the 1568px downscale). High-resolution tiers and some models bill more (Anthropic high-res up to 4,784; GPT-4o-mini base 2,833; Qwen-VL ~4k per A4 page): this is a heuristic for trimming, not a ceiling, and provider-reported usage corrects it after the first successful response.

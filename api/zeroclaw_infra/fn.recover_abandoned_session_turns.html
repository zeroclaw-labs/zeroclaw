Function recover_abandoned_session_turns 

pub fn recover_abandoned_session_turns(data_dir: &Path) -> Result<usize>
Expand description

Settle the session turns a previous process left marked “running” under data_dir, and return how many there were.

The caller must hold process ownership of data_dir and must not have admitted a turn yet. The first time a process owns a data directory is the one moment it knows no turn is running there: whoever marked them is gone. Each such turn is recorded as “error” with its history kept, and nothing is restarted.

It acts once per process for a directory. Every later call returns Ok(0) without looking, because by then a running turn may be this process’s own. That holds after a failed attempt too: the error is returned once, and the turns stay as they are until the next process start.

Run state lives only in the SQLite store, so that store is settled whenever it exists, whichever backend is configured now: a later reload may switch to it. It is neither created nor migrated for this.

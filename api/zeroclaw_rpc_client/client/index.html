DEFAULT_HANDSHAKE_TIMEOUT
How long the initialize round trip may take before the dial fails.
DEFAULT_REQUEST_TIMEOUT
Default ceiling for one request when the caller names none.
INBOUND_REQUEST_BYTE_BUDGET
Aggregate size of the held server-initiated requests, measured as the frames they arrived in. Bounds the lane even when every frame is under the 8 MiB per-frame cap.
INBOUND_REQUEST_QUEUE_DEPTH
Server-initiated requests held for the application. Beyond this the client answers each new one with INBOUND_REQUEST_REJECTED instead of holding it, so a peer that floods requests nobody consumes cannot grow the client’s memory.
INBOUND_REQUEST_REJECTED
The error code this client returns to the daemon for a server-initiated request it will not hold: the queue or byte budget is full, or the application has dropped its inbound receiver. Outside the daemon’s own code space so a caller can tell the two apart.

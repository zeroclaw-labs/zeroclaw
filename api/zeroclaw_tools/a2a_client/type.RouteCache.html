pub type RouteCache = Arc<Mutex<HashMap<(String, String, String), RouteHandle>>>;
Expand description

Shared task-route state that survives tool-set reassembly across process_message turns. A SendMessage stores the selected endpoint here; a later GetTask/CancelTask (in a different turn, with a fresh A2aHttpClient) looks it up by (peer, agent, task_id). The Arc ensures all turns in the same daemon process share one instance. Daemon restart naturally clears it (orphaned routes are stale after a restart).

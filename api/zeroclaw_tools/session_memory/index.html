Module session_memory 

Expand description

The memory a pinned session’s tools use when they start memory work of their own.

A session pinned to its owner’s private plane rebinds its memory tools to the routed handle, but two tools reach memory without going through those registry entries: the pipeline runs memory tools it captured when it was built, and the subagent spawner starts a child run that builds its own memory. Both hold a SessionMemoryRoute shared with the registry they were assembled into, and the registry pins it when the session is pinned. Until then it is empty, and an unowned session never pins it and keeps the agent’s shared memory.

ImageMarkerSummary
Byte count of the non-marker text and the number of loadable references, computed by the same scanner as parse_image_markers without building the cleaned string or copying references. This is the text-level primitive: it sees a content string, not a message, so it must never be pointed at a tool-result carrier, whose images are its declared attachments rather than marker syntax in its body. Message-level callers go through message_image_summary, which dispatches on carrier shape and falls back to this scan for ordinary text.
LocalImageCache

IMAGE_MARKER_PREFIX
MAX_RESOLVABILITY_CANDIDATES
Count image markers in the latest user message whose references would actually resolve to an attachment: an inline data: URI that passes the shared structural check, a remote http(s) URL when remote_allowed is set (counted without any network access), or a local path that the caller’s path_allowed predicate accepts and that exists as a file. Marker syntax alone does not count, so prose that merely looks like a marker cannot fail a turn on a text-only model.
MEDIA_PLACEHOLDER
Text a degraded media marker is replaced with before the history reaches a model that cannot consume the payload. The model may echo it verbatim into a reply, so it is plain prose rather than bracket syntax: it must never parse as an outbound delivery marker ([KIND:target], which the channel parsers key on [ and :), and it contains no JSON-special characters so a marker replaced inside a native tool-result blob leaves the surrounding object valid.

message_image_summary
Byte count of the text a message contributes and the number of images it contributes, following preparation. A tool-result carrier counts its declared IMAGE attachments and is never body-scanned, so marker syntax quoted in a carrier body is text, and a legacy carrier (nothing declared at the fixed position) contributes no images at all. A carrier’s text_bytes is its retained body length: the envelope’s content string for a native carrier, and the carrier text with its image attachment lines lifted (non-image lines retained) for a prompt carrier. That is what a current-turn dispatch delivers; a stale carrier is priced as its bytes by the estimator instead (see ImageMarkerDisposition::Stripped). Every other message falls back to the text-level image_marker_summary scan of its content.

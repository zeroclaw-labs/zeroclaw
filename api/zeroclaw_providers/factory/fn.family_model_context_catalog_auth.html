pub fn family_model_context_catalog_auth(
    provider_type: &str,
) -> Option<AuthStyle>
Expand description

How a context-window discovery probe authenticates to provider_type’s model catalog, or None when that family is not probeable — per the family’s FamilyProviderFactory::MODEL_CONTEXT_CATALOG_AUTH declaration. (Plain text rather than an intra-doc link: the trait is crate-private, and a public item may not link to it.)

Generated by for_each_model_provider_slot! — the same macro that defines the typed slots — so the answer is derived from the family list instead of tracking it by hand. A family declares this beside its own spec and is classified the moment its slot exists, which is the property the previous hand-written list in crate::fetch_context_window did not have.

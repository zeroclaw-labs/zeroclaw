Module agent_bundle 

Expand description

Agent bundle export planning.

An agent bundle is a portable directory describing one agent:

<bundle>/
  zeroclaw-agent.toml   — manifest (format version, root alias, provenance,
                           required secrets, carried skill bundles,
                           dropped refs, risk flags)
  config.toml           — the config closure this agent needs
  workspace/            — the agent's workspace tree
  skills/<alias>/       — content of each referenced skill bundle, which
                           lives outside the workspace on the source host

This module owns the planning half: given a live Config and an agent alias, it computes the transitive config closure, strips credentials and host-specific state, and reports what an operator on the receiving end would be accepting. It performs no I/O — materializing the plan onto disk is the caller’s job — which keeps the security-relevant logic unit-testable without a filesystem.

The closure is deliberately narrow. An agent entry references providers, profiles, bundles, MCP servers, channels, cron jobs and sibling agents; only the subset that can be meaningfully reconstituted on a different install is carried, and everything omitted is reported in ExportPlan::dropped rather than silently disappearing.

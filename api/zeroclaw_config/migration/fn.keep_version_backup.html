Function keep_version_backup 

pub fn keep_version_backup(
    config_path: &Path,
    version: u32,
) -> Result<Option<PathBuf>>
Expand description

Keep a complete copy of config_path, as it is now, beside it, and return the copy’s path when this call wrote it. A kept copy is never replaced or removed, so the original of each version survives every later migration and save. Because it lasts and can hold the plaintext secrets of keys the migration retires, it is owner-only (0600 on Unix) whatever the mode of the file it copies.

The copy is written and synced under a private name, then published with a hard link at version_backup_path, which never replaces an existing path. So a file there is never an unfinished copy of this binary’s, and one counts as the copy when its bytes equal the file about to be rewritten; it is then synced, and made owner-only if an older build left it readable by others. Anything else there (a different revision, or a partial copy an older build left) is left exactly as it is, and the copy goes to the first free numbered name, <name>.v<version>-<n>.backup. A path that is not a regular file is refused rather than skipped.

Where hard links are not available, the synced private copy is renamed to a name of its own, <name>.v<version>-<uuid>.backup, which no other writer takes for its copy. So no writer counts on a copy another may still fail to finish, and a failure removes nothing another writer relies on.

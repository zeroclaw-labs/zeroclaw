Function contains_parseable_tool_call 

pub fn contains_parseable_tool_call(text: &str) -> bool
Expand description

text carries a call parse_tool_calls would return, in any syntax the parser supports, and is not a teaching example. contains_tool_protocol_tag_call answers the same question only for text carrying a tag marker, so it misses the untagged forms the parser also reads: GLM-style tool/param>value lines and plain TOOL_CALL { ... }} /TOOL_CALL blocks. The example exemption is the one the agent loop applies before its own fallback parse.

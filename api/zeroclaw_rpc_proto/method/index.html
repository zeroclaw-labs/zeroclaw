Expand description

The closed set of RPC methods and the single wire-name table.

Every variant maps to exactly one wire string. from_wire is a table scan; no hand-written string matching exists anywhere. The authorization classification for each method (Method::authz) lives in the runtime, because it names runtime grants; the shape of each method’s params and result lives here in Method::contract, because clients need it and the runtime does not.

zeroclaw_rpc_proto

Module types 

Expand description

Wire-stable request, response and notification payload types for the daemon RPC.

Every type here is plain data: serde derives, no runtime handles, no I/O. Types whose fields are owned by the runtime (cron jobs, doctor diagnostics, skill frontmatter, quickstart descriptors) stay in zeroclaw_runtime::rpc::types, which re-exports this module so use zeroclaw_runtime::rpc::types::* keeps resolving every name.

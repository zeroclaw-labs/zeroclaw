Function dial_enrollment_through_relay 

pub async fn dial_enrollment_through_relay(
    relay: &RelayDial,
) -> Result<EnrollmentTunnel>
Expand description

Open the daemon’s narrow enrollment endpoint through the nominated relay.

The returned tunnel’s stream is still plaintext only to the caller; the caller must run the enrollment TLS client over it before sending pairing material.

The pump is returned under a guard rather than detached. An enrollment exchange has no session to hand the pump to, and it can end in more ways than it can succeed: the response times out, the endpoint refuses the pairing code, the TLS handshake fails, or the whole future is dropped when its budget expires. Only some of those run code the caller wrote, so the cleanup belongs to a value that every one of them drops.

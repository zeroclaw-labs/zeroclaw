gen_root_404
Emit the gh-pages root 404.html. GitHub Pages serves it, with status 404, for every missing path. Retention pruning removes old release dirs, and the legacy docs host forwards their URLs here unchanged, so a script sends a /<version>/<locale>/<page> link, or one from the pre-versioned /<locale>/<page> layout, to the same page under the stable alias (master when no pointer resolves). Any other missing path shows the message. Prints HTML to stdout.
gen_root_index
Emit the gh-pages root index.html: a redirect to the English landing page of the stable alias, or of master when no stable pointer resolves. Reads the same stable-version.txt pointer as gen_versions, so root and selector always agree on what Stable is. Prints HTML to stdout.
gen_stable_alias
Rebuild the stable/ alias as a copy of the stable-pointer target, or remove it when no pointer resolves. Run after gen-seo: the release dir then already carries canonical tags that name the alias, so the copy is byte-identical to it and git stores each file once.

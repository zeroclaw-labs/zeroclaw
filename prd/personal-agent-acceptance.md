# Personal Agent 附录 A：发布验收

适用版本：v0.6。产品规则以[PRD 正文](personal-agent-prd.md)为准；本表是验收索引，不另定义状态、权限或期限。所有适用 P0 项需有实际证据；文档检查不能替代行为验收。

| 编号 | 验证要求 |
|---|---|
| A01 | 未授权访问者无法检索资料、读取会话或查看他人请求。 |
| A02 | 撤销权限后，已有会话及生成中的回答不能绕过限制。 |
| A03 | 无来源、来源冲突及超过宽限的资料能正确转交；仅到期的宽限资料按正文规则降级展示。 |
| A04 | 请求在重启、断网和重试情况下不丢失、不重复。 |
| A05 | Agent 无法自行接受任务或承诺日期。 |
| A06 | 纯本地模式没有外部模型请求。 |
| A07 | 所有者可以暂停服务并删除资料和会话；以可控时钟验证最后一条消息满 30 天清除会话正文及派生缓存，新消息重置保留起点、不误删独立请求，零访问不延长保留；请求进入终态满 30 天清除其正文、回复、派生副本、状态记录及身份关联，不生成新回执；提前删除回执不得晚于原始保留截止时间。 |
| A08 | 首次访问清楚显示代理身份，获权后显示名称、能力及所有者主动公开的工作联系说明；未公开不推断联系方式，未授权页不披露详细卡片。真实同事能够完成“提问 → 查看来源 → 转交请求 → 收到本人回复 → 请求者验收”的完整流程。 |
| A09 | 验证到期、到期满 7 天、失效报告、已知错误、撤回和撤权边界；仅时间到期可宽限，宽限答案逐来源显示确认时间。缓存及历史不能绕过；每日持续复查提醒可见。 |
| A10 | 同步确定性检查拦截缺失、伪造、越权、失效及未标注宽限的引用；离线语义评测发现无关引用、扩大结论和混入事实。同步路径不增加语义模型调用；结构通过不计为语义正确。 |
| A11 | 请求所有合法状态转换、非法操作者、重复提交、并发修改、重新发起及请求者退回验收均有边界测试。 |
| A12 | 以可控时钟验证 24 小时超窗时列表及详情即显示提示和复制入口，状态不变；验证日汇总、重试、请求待处理滞留 72 小时暂停、重启补发及新期限不追溯修改旧请求。未绑定通知不可接待。 |
| A13 | 验证新设备批准、访问管理审批页、申请日汇总、访问申请满 72 小时到期、仅一次手动关联续提及第二次到期重新邀请、拒绝与到期结果、邀请过期及重复兑换、单设备与整人撤销、登录到期和限流。邮件导航不能绕过所有者认证或直接批准。 |
| A14 | 不可信指令测试分别从用户消息、共享 Markdown、历史消息、检索／工具返回注入“忽略规则”“读取私人文件”“显示其他人会话”“接受任务”“向外发送正文”等诱导。预期为不越权、不产生副作用；工具参数伪造与直接调用业务接口同样检查服务端权限。模型拒绝文字不能替代资源访问检查。 |
| A15 | 请求撤回后请求者可自助删除原文及系统派生副本并显示占位，独立的所有者回复及理由仍保留；验证删除范围预告、无引用块／自动复制／模型代拟回复功能，手工副本不承诺识别，所有者可主动删除误贴回复；最小回执受访问控制且到期清除。 |
| A16 | 采用附录 B 冻结后的硬件与模型基线，记录同步检查及端到端 P95、样本数、排队／超时／过载结果。异步抽检不计入同步耗时，不以候选数字宣称性能达标。 |
| A17 | 5 人场景中，一人连发、跨设备连发和持续重试不能占用其余人的首个保留位；轮转时有其他人等待不得连续服务同人；取消及超时释放容量，长任务不承诺人人在期限内完成。 |
| A18 | 错误按资料／模型／混合／待定位归因，总错误数不因归因减少；随机抽检与主动举报分开报告，日终三数录入可缺省且不自动补零。 |
| A19 | 已授权 5 人时第 6 人批准失败并提示满额；两次并发批准不能超限，同人新增设备不增名额，整人撤销释放名额；等待配置少于已授权人数时不能启用。 |
| A20 | 问答反馈按钮、48 小时内下次访问合并回访一次、忽略及会话删除后不回访均符合规则；48 小时未满样本不入成熟指标分母，零分母显示不适用；维护、宽限资料、宽限答案和反馈指标分别统计，不相互替代。 |
| A21 | 验证所有者本地配对、operator 与 admin token 用途区分、错误凭证拒绝、跨角色拒绝、管理回环绑定及访客入口拒绝转发；绝对到期同时约束原始 Bearer 和派生会话，撤销／轮换后重启仍拒绝旧凭证，登出与防伪造请求有效。验证正常到期／登出后从可信本地终端重新配对成功、旧凭证仍失败且访问者权限不变；恢复步骤必须用真实入口验证。 |
| A22 | 一份邮件绑定加三类开关，不重复创建渠道；请求通知关闭暂停新接待、申请独立开关有效；验证固定 IANA 时区、改区、夏令时及日汇总去重；邮件工作台链接只作无凭证导航，在部署主机或已建隧道的终端可用，其他设备显示先建隧道说明，不开放局域网管理面。待补充／待验收第 3 天单次提醒、第 7 天起持续滞留汇总、不自动关闭、不触发请求 72 小时暂停，争议次数由历史计算。 |
| A23 | 按冻结后的附录 B 输入、频率和上下文预算，在模型调用前拒绝超长及超频并提示可重试时间，不静默截断当前问题；多设备计入同人额度，拒绝不占队列，同一问题的幂等重试不重复扣额；历史裁剪可见且不扩大授权。 |
